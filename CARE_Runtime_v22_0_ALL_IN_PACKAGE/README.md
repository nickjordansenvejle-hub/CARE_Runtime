# CARE Runtime v22.0 — Quality + Trust Layer

This version adds a trust layer around the public CARE runtime.

## Adds
- Quality + Trust Home
- Live App Health Check
- Broken Page Detector
- EN/DK Translation Scanner
- Public Claim Safety Audit
- Download / Report Audit
- Mobile Readability Score
- Reviewer Red-Team Scoreboard
- Streamlit Deployment Checklist
- Release Notes Generator
- What CARE Is / Is Not
- Quality trust manifest

## Run
```powershell
py -m pip install -r requirements.txt
py -m streamlit run app.py
```

## Boundary
Quality is not authority.
Health is not permission.
Translation is not bind.
Download is not execution.
Live app is not deployment.
No bind -> no human consequence.
