# CARE Runtime v20.0 — Executive Product Platform

This version makes CARE feel more like a public product platform.

## Adds
- Executive Dashboard Pro
- Interactive CARE Map
- Release Center
- GitHub + Zenodo Center
- World Impact Center

## Run
```powershell
py -m pip install -r requirements.txt
py -m streamlit run app.py
```

## Boundary
Dashboard is not authority.
Map is not bind.
Release readiness is not deployment.
GitHub/Zenodo links do not create authority.
Founder story is context only.
No bind -> no human consequence.
