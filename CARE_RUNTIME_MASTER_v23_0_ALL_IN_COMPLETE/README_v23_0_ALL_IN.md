# CARE Runtime v23.0 — Public Platform Edition

This version strengthens CARE as a public platform.

## Adds
- Public Platform Home
- Live Route Explorer
- Health Score Engine
- Deployment Center
- Public Reviewer Mode
- CARE Statistics
- Platform Launch Checklist
- Public Readiness Report
- Public platform manifest

## Run
```powershell
py -m pip install -r requirements.txt
py -m streamlit run app.py
```

## Boundary
Route search is not bind.
Health score is not permission.
Deployment view is not deployment authority.
Reviewer feedback is not authority.
Statistics are not execution.
No bind -> no human consequence.
